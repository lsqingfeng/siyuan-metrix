## 🛠️ 30 秒极速上手

1. **启用思源插件**：在思源笔记「集市 -> 插件」搜索 **Metrix** 安装启用（或将 `package.zip` 解压至 `data/plugins/siyuan-metrix`）；
2. **安装浏览器伴侣**：在思源笔记按 `⌥M` 唤起控制台 -> 点击右上角 **「🧩 伴侣扩展」** 一键导出安装包至下载目录并解压 -> 打开浏览器 `chrome://extensions/` 开启「开发者模式」-> 点击「加载已解压的扩展程序」选中解压文件夹；
3. **一键并发分发**：在任意笔记按 `⌥M`，勾选目标平台，点击 **「🚀 一键全网分发至草稿箱」** 即刻完成！

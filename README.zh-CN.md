# 🚀 Metrix: 商业级思源笔记多平台矩阵一键分发套件

Metrix 是首个完全基于前端技术栈与本地安全通信构建的**自媒体矩阵自动化多平台发布系统**。专为程序员、架构师与技术博主打造，从思源笔记直接把文章无缝打入知乎、稀土掘金、CSDN、今日头条、B站专栏及微信公众号。

## 📦 套件组成与目录结构

- `siyuan-plugin/`：思源笔记插件源码与发布包
  - `index.js`：插件完整运行时（含 Bridge 服务端、Canvas 封面渲染器、主题引擎与 License 管理器）
  - `index.css`：原生高颜值样式与设置对话框样式
  - `plugin.json`：思源插件元数据 (v2.0.0)
- `browser-companion/`：Chrome / Edge 浏览器伴侣扩展
  - `manifest.json`：Manifest V3 配置文件
  - `src/`：扩展源代码（Bridge 监听、主调度器与各平台注入脚本）
  - `dist/unpacked/`：解包后可直接在浏览器加载的扩展目录
  - `dist/metrix-companion.zip`：可直接导入或分发的 ZIP 安装包
  - `scripts/build.js`：扩展生产环境构建与代码混淆脚本
- `tools/`：商用配套运营工具
  - `generate_license.js`：离线专业版授权码生成与校验工具
- `COMMERCIAL_PRICING_GUIDE.md`：商业化定价方案、电商平台发卡配置与商业变现指南

## ⚡ 核心优势与技术突破

1. **彻底告别 Python 与环境配置**：
   以往同类工具动辄要求用户安装 Python 3.10+、配置虚拟环境、安装 Playwright 及 Chromium 内核，普通用户上手门槛极高且容易因环境缺失而报错。Metrix 100% 采用 Node.js + 原生浏览器技术，开箱即用。
2. **零封号风险（复用正常浏览器）**：
   不伪造无头浏览器环境，直接在用户日常使用的真实浏览器上下文中注入草稿，完全保留真实设备的指纹、Cookie 与登录状态，有效抵御平台的风控拦截。
3. **极客内联富文本排版**：
   内置经典少数派与极客蓝排版样式，代码块具备 Mac 🔴🟡🟢 终端窗口圆标，排版优雅清爽，一键复制微信公众号富文本。
4. **离线数字验签商业体系**：
   内置轻量可靠的离线校验算法，无需架设高成本高风险的中心授权服务器，永不断网，100% 保护用户隐私数据。

## 🛠️ 快速上手

1. **安装思源插件**：将 `siyuan-plugin` 软链接或复制至思源 `data/plugins/siyuan-metrix`；
2. **安装浏览器伴侣**：在 Chrome 扩展管理界面中勾选「开发者模式」，点击「加载已解压的扩展程序」，选择 `metrix/browser-companion/dist/unpacked`；
3. **日常发布**：在思源笔记中按 `⌥M`，挑选目标平台，点击「一键全网分发至草稿箱」，即刻完成多平台草稿写入。
